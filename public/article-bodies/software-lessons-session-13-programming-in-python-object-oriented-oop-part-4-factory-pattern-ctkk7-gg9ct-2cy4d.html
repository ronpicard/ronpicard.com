Session 15 of Software Lessons, “Visual Studio Docker Dev Containers and Protocol Buffers Part 3,” runs about 26 minutes.

What this session covers

  • Visual Studio Code Docker dev containers
    • Protocol Buffers
      • Installation
      • What Protocol Buffers are and how they work

    Key ideas

    • A dev container runs your development environment inside a Docker container, so the compiler, libraries and tools are the same on every machine.
    • Docker packages an application and its dependencies as an image, and a container is a running instance of that image, isolated from the host system.
    • Visual Studio Code can attach to a container and work inside it as if it were local, while the project files stay available from the host.
    • Protocol Buffers are a language-neutral way to describe structured data in a schema file and generate code from it for several languages.
    • Messages encoded as Protocol Buffers are compact binary data, which makes them well suited to sending between services.
