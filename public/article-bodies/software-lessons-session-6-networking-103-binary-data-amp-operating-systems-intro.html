Session 6 of Software Lessons, “Networking 103: Binary Data and Operating Systems Intro,” runs about 30 minutes.

What this session covers

  • IPv4 and IPv6 formats and packet structure
  • Binary to ASCII and integers, and back
  • Bits and bytes
  • Ping versus bandwidth
  • Introduction to operating systems
    • Windows
    • Linux
    • Unix
    • OSX
    • RTOS
  • Introduction to kernels and STIGs

Key ideas

  • A packet has a header, which holds fields such as the source and destination addresses, followed by the data it carries.
  • An integer is stored as a binary number, and text is stored by mapping each character to a number, as ASCII does.
  • Converting between binary and decimal means reading each bit as a power of two.
  • The kernel is the core of an operating system, controlling memory, processes and access to hardware.
  • A real-time operating system (RTOS) is designed to respond within guaranteed time limits, and STIGs are published security configuration guides for hardening systems.
