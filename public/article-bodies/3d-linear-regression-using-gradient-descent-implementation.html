In this notebook, we will walk through how to perform linear regression using gradient descent with two input features. The goal for this example is to predict what a good market price should be for your home, given previous data on prices, sizes (square footage) and numbers of bedrooms. The inputs to our model are the size of a home and its number of bedrooms, and the output is a market price.

With two inputs and one output, the model is a plane in three dimensions rather than a line in two. This is the second of two homework exercises from a deep learning course, written in plain NumPy.

The data and the model

The data file has three columns: size in square feet, number of bedrooms, and price. Each row is one house, and the whole file is used for training. The model is a plane:

h(x) = θ₀ + θ₁ · size + θ₂ · bedrooms

Square footage runs into the hundreds or thousands while bedroom counts are single digits, so we standardise every column, including price, by subtracting its mean and dividing by its standard deviation. As in the 2-D version, this keeps the cost surface from becoming a long narrow valley and lets one learning rate work for all three parameters.

The vectorised form

The key idea is to avoid writing a loop over houses or over parameters. We build a matrix X with one row per house: a 1 for the bias, the normalised size, and the normalised number of bedrooms. With the parameters in a 3 by 1 vector θ, a single product gives every prediction at once:

ŷ = Xθ

The cost and its gradient follow directly:

J(θ) = (1 / 2m) · (Xθ − y)ᵀ(Xθ − y)
∇J = (1 / m) · Xᵀ(Xθ − y)
θ ← θ − α · ∇J

Here m is the number of houses. Xᵀ(Xθ − y) adds up, for each parameter, the error on every house weighted by that parameter's feature. Because the first column of X is all ones, the first entry of the gradient is simply the average error, which is the bias update.

Training

We start θ at (1, 1, 1) and run 100 iterations of batch gradient descent with α = 0.1. The loop is the same as in the 2-D post; only the width of X has changed.

for i in range(interations):
    hx = np.dot(x, theta) # M X 3 times 3 X 1 = M X 1
    hx_minus_y = hx - y
    hx_minus_y_transpose = np.transpose(hx_minus_y)
    j = np.dot(1/(2*m), np.dot(hx_minus_y_transpose, hx_minus_y))

    x_transpose_x = np.dot(np.transpose(x), x)
    x_transpose_x_theta = np.dot(x_transpose_x, theta)
    x_transpose_y = np.dot(np.transpose(x), y)
    dj_dtheta = np.dot(1/m, x_transpose_x_theta - x_transpose_y)

    theta = theta - np.dot(alpha, dj_dtheta)

The run takes about 2 milliseconds and ends with a cost of 0.00877 in normalised units. The notebook's learning curve shows the cost levelling off quickly, in about 20 iterations.

Predicting a price

To use the model, we price a 925 square foot apartment with 2 bedrooms, as if it were a house. The new listing has to go through exactly the same steps as the training data:

  1. Normalise the size and the bedroom count with the training means and standard deviations.
  2. Compute θ₀ + θ₁ · size + θ₂ · bedrooms. The model returns −1.296, a price about 1.3 standard deviations below the average house.
  3. Undo the price scaling: multiply by the price standard deviation and add the price mean.

The result is $166,000.27. The home being priced is the author's own apartment, treated as if it were a house.

Takeaway

Going from one feature to two required no change to the algorithm, only a wider X. Writing the cost and gradient with matrices means the same few lines handle any number of features. The full notebook, with every cell and plot, is on GitHub.
