Session 1 of Software Lessons, “Computer Architecture 101: Basic Components,” runs about 27 minutes.

What this session covers

  • Von Neumann architectures
  • Core hardware
    • CPUs
    • GPUs
    • RAM
    • Hard drives, SSDs and M.2 drives
  • BIOS and the operating system
  • ARM versus x86

Key ideas

  • A Von Neumann architecture keeps programs and data in the same memory, and the processor fetches instructions from that memory one after another.
  • The CPU executes instructions, RAM holds the data and code in use right now, and drives keep data when the power is off.
  • A GPU has many simple cores and is built for work that can be done in parallel, such as graphics and numerical computation.
  • The BIOS runs when a computer starts, checks the hardware and hands control to the operating system, which manages the hardware for programs.
  • ARM and x86 are different instruction set architectures, so a compiled program targets one or the other.
