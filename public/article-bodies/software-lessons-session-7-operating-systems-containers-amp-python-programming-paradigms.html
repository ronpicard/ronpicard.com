Session 7 of Software Lessons, “Operating Systems, Containers and Python Programming Paradigms,” runs about 24 minutes.

What this session covers

  • Operating systems and kernels
  • Virtual machines (VirtualBox, VMware)
  • Containers (Docker, the Docker runtime)
  • Programming language paradigms
    • Command programming (command line and terminal)
    • Procedural programming: variables, for and while loops, if/else control flow, comparison, logical and arithmetic operators
    • Functional programming: functions and code reuse
    • Object-oriented programming: classes, abstraction, polymorphism and inheritance
    • Aspect-oriented programming: cross-cutting function wrappers
  • Introduction to Visual Studio Code
  • Introduction to running Python code

Key ideas

  • A virtual machine emulates a whole computer with its own operating system, while a container shares the host kernel and isolates only the application and its dependencies.
  • Containers are usually lighter and faster to start than virtual machines because they do not boot a separate operating system.
  • A programming paradigm is a style of organizing code; many languages, Python among them, support several.
  • Procedural code is a sequence of steps using variables, loops and conditionals, and functional code builds programs from reusable functions.
  • Aspect-oriented programming wraps behavior such as logging around functions without changing the functions themselves.
