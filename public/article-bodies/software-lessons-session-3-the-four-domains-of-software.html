Session 3 of Software Lessons, “The Four Domains of Software,” runs about 28 minutes.

What this session covers

  • The four domains
    • Web development
    • Desktop apps and data science
    • Robotics and embedded systems
    • Networking and protocols
  • Languages, frameworks and protocols for each domain
  • Networking equipment
    • Routers
    • Access points
    • Modems
    • WAN and LAN
    • Switches
  • Which path fits which career goals

Key ideas

  • Web development splits into front-end code that runs in the browser and back-end code that runs on a server and answers requests.
  • Desktop applications and data science work run on a personal computer or server and often process local files or large datasets.
  • Embedded systems run on small dedicated hardware, often with tight limits on memory, power and timing, as in robotics.
  • A protocol is an agreed set of rules for exchanging data, which lets different devices and programs communicate.
  • A LAN connects devices in a small area such as a home or office, and a WAN connects networks across larger distances; routers move traffic between networks and switches connect devices within one.
