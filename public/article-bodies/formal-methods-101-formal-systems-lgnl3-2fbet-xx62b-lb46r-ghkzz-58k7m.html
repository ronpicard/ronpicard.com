Introduction

Zero-order logic (also known as propositional logic or propositional calculus) is the foundation of most formal logic systems.

It has no notion of variables, only TRUE or FALSE propositions (statements) represented by symbols (usually A, B, C, …). Logical operators (negation and the binary connectives) describe how an argument flows from one proposition to the next.

Propositions

A proposition is simply a TRUE or FALSE statement.

  • Proposition A: All men are mortal. Proposition A is TRUE.
  • Proposition B: My cat is a dog. Proposition B is FALSE.

Operators

  • Negation gives the opposite of a proposition. If A is TRUE, ¬A is FALSE; if A is FALSE, ¬A is TRUE.
  • Conjunction makes the expression TRUE if and only if (iff) propositions A and B are both TRUE.
  • Disjunction makes the expression TRUE iff proposition A or proposition B (or both) is TRUE.
  • Material implication means that if A is TRUE, then B is TRUE. It gives no information about B when A is not TRUE.
  • Material bijection means that if A is TRUE, then B is TRUE, and if B is TRUE, then A is TRUE; if A is FALSE, then B is FALSE, and if B is FALSE, then A is FALSE. In other words, the Boolean values of A and B are never different. It is equivalent to implication both ways:

(A → B) ∧ (B → A)

Order of operations

Operators are evaluated in this order:

  1. ¬ is evaluated first.
  2. ∧ is evaluated next.
  3. ∨ is evaluated next.
  4. → is evaluated last (and so is ↔).

Argument construction

An argument chains propositions together with the operators. Take two propositions and a conclusion:

  • Proposition A: All men are mortal.
  • Proposition B: Socrates is a man.
  • Proposition C: Socrates is mortal.

The argument "All men are mortal and Socrates is a man; therefore (implies) Socrates is mortal" is written formally as:

A ∧ B → C
