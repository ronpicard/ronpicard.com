Session 4 of Software Lessons, “Networking 101: Internet Fundamentals,” runs about 27 minutes.

What this session covers

  • Addressing and naming
    • IP addresses
    • ISPs
    • DNS
    • IPv4 versus IPv6
    • Leasing IP addresses on a WAN
    • Netmasking and subnets, legal and illegal IP addresses
    • Class A, B and C subnets
  • Physical signals
    • The speed of light in fiber and the speed of electricity
    • The electromagnetic spectrum
  • Introduction to binary bits and bytes

Key ideas

  • An IP address identifies a device on a network, and DNS translates human-readable names into IP addresses.
  • IPv4 addresses are 32 bits long and IPv6 addresses are 128 bits long, which gives IPv6 a far larger address space.
  • A netmask splits an address into a network part and a host part, which defines a subnet.
  • Some address ranges are reserved, so not every IPv4 address is valid for ordinary use on the public internet.
  • A bit is a single 0 or 1, and a byte is eight bits, so one byte can hold 256 different values.
