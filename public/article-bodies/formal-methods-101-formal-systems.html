What a formal system is

A formal system is a set of formulas (axioms, or formulas derived from axioms) that are used to infer properties, theorems, or additional truths. Axioms can be thought of as a set of given assumptions or rules about the system.

Models

An interpretation of the axioms (and of the truths derived from them) is known as a model. For example, in first-order logic without quantifiers and with only Boolean-valued variables, a model is one assignment of Boolean values to the predicate variables. All possible models are all possible assignments. For such basic predicates, all possible models can be listed in a truth table.

Two new symbols

Syntactic entailment: ⊢

Also known as syntactic consequence, syntactic implication, or logical implication. It is functionally the same as the binary version known as material implication, but lives in the "meta" context of a system.

Let Γ be the set of formulas (axioms, or formulas derived from axioms) of a formal system S, and let φ be a property. We write:

Γ ⊢ φ

This says that φ is provable (derivable) from the formulas Γ of the formal system S. It is sometimes written with the system as a subscript, Γ ⊢ₛ φ.

Semantic entailment: ⊨

Also known as semantic consequence or semantic implication. It relates to truths that hold given the set of formulas Γ of the formal system S. We write:

Γ ⊨ φ

This says that φ is true (not necessarily derivable) in all models, that is, all possible interpretations, of the formulas Γ of the formal system S. It is sometimes written Γ ⊨ₛ φ.

Syntactic and semantic entailment by example

Take these axioms and this property:

Γ = { (A ∧ ¬B) → C, (C ∨ D) → E }
φ = ((A ∧ ¬B) ∨ D) → E

Syntactic entailment

Does φ hold, given Γ? A derivation:

  1. (A ∧ ¬B) → C (axiom)
  2. (C ∨ D) → E (axiom)
  3. Substitute 1 into 2 to get ((A ∧ ¬B) ∨ D) → E

Because φ is syntactically derivable from Γ, we write Γ ⊢ φ.

Semantic entailment

Does φ hold, given Γ? Here we look at the models, the assignments that make the formulas true. There is no model of Γ that makes the antecedent of φ true and E false, so there is no interpretation in which the axioms hold and φ fails. Because φ is semantically valid from Γ, we write Γ ⊨ φ.

Completeness and soundness

Semantic completeness

A formal system is semantically complete if all tautologies are theorems (derivable truths):

(⊨ φ) → (⊢ φ)

Strong completeness

A formal system is strongly complete if every semantic truth in the system can be syntactically derived (proved); that is, every truth is provable:

(Γ ⊨ φ) → (Γ ⊢ φ)

Intuitively, strongly complete means that, given Γ, it is possible to compute all semantic consequences.

Refutation-completeness

A formal system S is refutation-complete if it can derive false from every set of unsatisfiable formulas:

(Γ ⊨ ⊥) → (Γ ⊢ ⊥)

All strongly complete systems are also refutation-complete. Intuitively, refutation-complete means that it is possible to check whether φ is a semantic consequence.

Soundness

A formal system is sound if every derivable (provable) syntactic truth in the system is a semantic truth; that is, no false statement can be proved:

(Γ ⊢ φ) → (Γ ⊨ φ)

Zero-order (propositional) logic is both sound and complete.
