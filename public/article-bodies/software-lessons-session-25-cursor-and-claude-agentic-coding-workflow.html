Session 25 of Software Lessons, “Cursor and Claude: Agentic Coding Workflow,” runs about 24 minutes.

What this session covers

  • Agentic programming with AI coding assistants
  • The Cursor editor workflow with Claude
  • Practical patterns for LLM-assisted development
  • A walkthrough of using Cursor and Claude for agentic software development, from prompts to shipping code

Key ideas

  • Agentic programming means giving a coding assistant a goal and letting it plan and carry out several steps, such as reading files and editing code, rather than answering one prompt at a time.
  • Cursor is a code editor with built-in assistant features, and Claude is a large language model (LLM) that can be used as the assistant.
  • The quality of the result depends heavily on how clearly the task and its constraints are described in the prompt.
  • Generated code still needs review and testing, because a language model can produce output that looks right and is not.
  • Small, well-scoped tasks with a way to check the result tend to work better than broad requests.
