Abstract

The use of security systems is becoming more prevalent in this modern age. With the advent of machine learning algorithms, there is a unique opportunity to integrate machine learning algorithms into modern camera-based security systems. We present an inexpensive, lightweight computer vision security system with an integrated deep neural network. The security system uses active image classification to detect intruders and provide notification and a video to the owner over email. In addition, the system maintains an integrated graphical user interface controller as well as an android application controller.
